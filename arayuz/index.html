The Odin Project ile ilk web sayfami basariyla olusturuyorum.

Evdeki salcalar her yeri kapliyor. Mikrodalgayi calistiramiyorum. Yemekleri isitamadigimden dolayi ac kaldim.

Mentalist Dram, Gizem ve Polisiye turunde bir dizidir. Bu diziyi izlerken kendimi cok iyi hissediyorum. Bütün günün stresini atiyorum.

The Odin Project ile web gelistirme yolculuguma basladim. Bu sayfayi olusturmak icin HTML ve CSS kullanarak temel web gelistirme becerilerimi gelistiriyorum.

HTML ve CSS

HTML ve CSS, web sayfalarinin temel tasarim ve yapi tasarim dilleridir. HTML, web sayfalarinin yapisini olusturmak icin kullanilirken, CSS ise bu yapilari stilize etmek icin kullanilir. Bu iki dil, web gelistirme alaninda temel beceriler arasinda yer alir.

JavaScript

JavaScript, web sayfalarina dinamik ozellikler eklemek icin kullanilan bir programlama dilidir. Bu dil, web sayfalarina interaktif ozellikler eklemek icin kullanilir ve web gelistirme alaninda onemli bir beceridir.

Web Gelistirme

Web gelistirme, web sayfalarini ve uygulamalari olusturma islemidir. Bu islem, HTML, CSS ve JavaScript gibi diller kullanilarak gerceklestirilir.

Benim Hedeflerim

Benim hedefim, web gelistirme alaninda uzmanlasmak ve kendi projelerimi olusturmak. Bu hedefime ulasmak icin, The Odin Project gibi kaynaklardan yararlanarak kendimi gelistiriyorum ve web gelistirme alaninda deneyim kazaniyorum.
